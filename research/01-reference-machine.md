# Reference machine: Philips EP2230/10

## Observed identification

Reference machine:
- Philips EP2230/10
- Main PCB marking: 1.9.30.330.00 V10
- Main PCB label: 421941311941/04
- UI PCB silkscreen: OMNIA UI ENTRY 1.9.30.332.00 V05
- UI PCB label: 421941311861/03
- Mainboard test pads visibly labelled U_TX, U_RX, GND and +5V

## Repair history relevant to research

The machine previously failed to grind. Direct grinder activation produced no movement. Physical inspection later found the grinder mechanically jammed. After cleaning, normal electronic operation returned. This is useful because it prevents an unrelated grinder fault from contaminating later protocol/UI experiments.

During disassembly the ground-coffee outlet conveyor/chute was damaged. Replacement part identified by the owner: 421941230122, Ground Coffee Outlet Conveyor V2.

## Why this machine is useful

The EP2230/10 has LatteGo, coffee, espresso, cappuccino and hot-water capability, making it a useful bridge between basic EP22xx models and richer EP32xx LatteGo models. It also exposes clearly labelled serial-looking test pads and uses an OMNIA UI board.

## Preserve before modification

Before any permanent modification, retain photographs of:
- mainboard front/back;
- UI front/back;
- connector orientation;
- cable wire order;
- all labels/revisions;
- machine type label.

No original harness should be cut during the research phase.
