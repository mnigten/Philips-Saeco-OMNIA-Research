# Captures

Store raw serial captures here. Never edit the original capture after collection.

For each capture also record:
- machine model and PCB revisions;
- wiring/sniffer hardware;
- baud/framing;
- machine state before action;
- exact physical button/action;
- timestamps if available;
- whether the ESP was passive/read-only.

Derived/decoded versions should be separate files so the raw evidence remains intact.
