# Upstream research

This repository indexes upstream research rather than copying it wholesale. Preserve upstream attribution and licences when reusing code.

## Philips
- https://github.com/chris7topher/SmartPhilips2200 — Philips 2200, ESP8266/MQTT and serial interception. MIT.
- https://github.com/TillFleisch/ESPHome-Philips-Smart-Coffee — ESPHome 2200/3200 implementation with explicit EP2220, EP2235, EP3243 and EP3246 model profiles.
- https://github.com/mkorenko/esp-phillips-3200 — ESP32/ESP8266 control library for Philips 3200. MIT.
- https://github.com/flashmandv/phillips-3246-smart — EP3246-focused fork of mkorenko's project.
- https://github.com/markobel/Philips-EP5400-ESPHome — later-generation comparison; do not assume packet compatibility.

## Saeco
- https://github.com/OpHaCo/smart_coffee_machine — earlier Saeco Intelia reverse engineering. Architectural/history reference only until OMNIA compatibility is demonstrated.

## Evidence labels
Every finding should be marked as one of:
- OBSERVED: measured/read on our EP2230/10
- UPSTREAM: demonstrated by a cited project
- INFERRED: consistent with evidence but not directly verified
- HYPOTHESIS: awaiting a test
